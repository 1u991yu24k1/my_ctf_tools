# OBS Studio + VLCによるWebカメラ録画手順

## 1. 目的と構成

この手順では, Logicool C922 Pro Stream WebcamをOBS Studioへ取り込み, 会場のスクリーンを録画します. 録画後はVLC Media Playerで再生し, 必要に応じてインタラクティブズームでスクリーン部分だけを拡大表示します.

基本構成は次のとおりです.

```text
会場の投影スクリーン
    ↓
Logicool C922 Pro Stream Webcam
    ↓ USB
OBS Studioで録画
    ↓
MKVまたはMP4ファイル
    ↓
VLC Media Playerで再生, 必要に応じてズーム
```

重要な点は次の2つです.

- OBSのプレビューは, 表示したまま録画して問題ありません.
- VLCのインタラクティブズームは再生時だけの表示処理であり, 録画ファイルそのものは変更しません.

---

## 2. OBS Studioの初期設定

### 2.1. シーンを作成する

1. OBS Studioを起動します.
2. 左下の`シーン`欄に既存のシーンがあれば, そのまま使用できます.
3. 新しく作る場合は, `シーン`欄の`+`を押します.
4. 任意の名前を付けます.

例.

```text
プレゼン録画
```

### 2.2. C922を映像ソースとして追加する

1. `ソース`欄の`+`を押します.
2. `映像キャプチャデバイス`を選択します.
3. `新規作成`を選択します.
4. 任意の名前を付けます.

例.

```text
C922
```

5. `デバイス`で次を選択します.

```text
C922 Pro Stream Webcam
```

6. `解像度/FPSタイプ`を`カスタム`にします.
7. スライドの文字を優先する場合は, 次の設定を推奨します.

```text
解像度: 1920x1080
FPS: 30
```

C922で60fpsを使う場合は, 一般に解像度を1280x720へ下げる必要があります. 投影スライドの文字を撮る用途では, 1920x1080, 30fpsの方が適しています.

8. `映像フォーマット`は, まず`MJPEG`を試します.
9. 正常に映像が表示されない場合は, `NV12`, `YUY2`, または`デバイスの既定値`を試します.
10. `OK`を押します.

### 2.3. カメラの画角を調整する

OBSのプレビューを見ながら, C922の向きと設置位置を調整します.

推奨状態は次のとおりです.

- スクリーンができるだけ大きく映る.
- カメラを可能な限りスクリーン正面に置く.
- 観客の頭や会場設備が入りにくい高さに固定する.
- 三脚などを使い, 本番中に動かないようにする.
- デジタルズームは可能な限り使わない.

ソフトウェア上で拡大すると, 元の画素を引き伸ばすため, 文字がぼやけやすくなります. 可能なら, カメラをスクリーンへ近づけてください.

### 2.4. フォーカスと露出を確認する

`ソース`欄のC922を選択し, `プロパティ`を開きます.

`ビデオの設定`を押すと, カメラドライバ側の設定画面が開く場合があります.

スクリーン撮影では, 次の設定が有効です.

```text
オートフォーカス: 必要に応じてOFF
フォーカス: スクリーンへ合わせて固定
自動露出: 必要に応じてOFF
露出: スクリーンの白背景が白飛びしない位置まで下げる
ゲイン: できるだけ低め
ホワイトバランス: 必要に応じて固定
```

発表者や観客がカメラの前を横切ると, オートフォーカスが人物へ移り, スクリーンがぼけることがあります. スクリーンまでの距離が固定されている場合は, フォーカスを固定した方が安定します.

---

## 3. OBSの映像設定

1. OBS右下の`設定`を押します.
2. `映像`を開きます.
3. 次のように設定します.

```text
基本キャンバス解像度: 1920x1080
出力解像度: 1920x1080
FPS共通値: 30
```

C922を1920x1080で使用する場合は, OBS側も1920x1080にそろえます.

### 3.1. プレビュー表示倍率について

OBSプレビュー下部に表示される`44%`などの値は, OBS画面内での表示倍率です.

これは録画倍率ではありません. この値を変更しても, 保存される動画のズーム倍率や解像度は変わりません.

---

## 4. 録画設定

### 4.1. 簡単な設定

1. `設定`を開きます.
2. `出力`を開きます.
3. `出力モード`を`基本`にします.
4. `録画`欄を設定します.

推奨例.

```text
録画パス: 任意の保存先
録画品質: 高品質, ファイルサイズ中
録画形式: MKV
エンコーダ: 使用可能なハードウェアエンコーダ
```

保存先の例.

```text
C:\Users\<ユーザー名>\Videos\OBS
```

ハードウェアエンコーダの例.

```text
NVIDIA NVENC H.264
Intel Quick Sync H.264
AMD HW H.264
```

利用できない場合は, ソフトウェアエンコーダを使用して構いません.

### 4.2. MKVを推奨する理由

録画形式はMKVを推奨します.

MP4へ直接録画している途中でOBSやWindowsが異常終了すると, ファイル全体が再生できなくなる場合があります. MKVは, 録画途中で異常終了しても, それまでの内容を回収できる可能性が高い形式です.

MP4が必要な場合は, 録画後に再多重化します.

---

## 5. OBSで録画する

### 5.1. 録画前確認

録画前に次を確認します.

- `ソース`に`C922 Pro Stream Webcam`が1つだけ登録されている.
- OBSプレビューにスクリーンが映っている.
- 解像度が1920x1080になっている.
- フレームレートが30fpsになっている.
- スクリーンの白い部分が白飛びしていない.
- 小さい文字にピントが合っている.
- 録画先フォルダに十分な空き容量がある.
- 必要な音声入力だけが有効になっている.

### 5.2. 録画開始

1. OBS右下の`録画開始`を押します.
2. 録画中は, ボタンが`録画終了`に変わります.
3. OBSプレビューは表示したままで問題ありません.
4. 撮影が終わったら`録画終了`を押します.

録画開始前にプレビューをOFFへ切り替える必要はありません.

### 5.3. 録画ファイルを確認する

保存先が分からない場合は, OBSのメニューから次を選びます.

```text
ファイル
→ 録画を表示
```

エクスプローラーで録画先フォルダが開きます.

---

## 6. MKVをMP4へ変換する

OBSでは, 再エンコードせずにMKVをMP4へ再多重化できます.

1. OBS上部の`ファイル`を開きます.
2. `録画の再多重化`を選択します.
3. 録画した`.mkv`ファイルを指定します.
4. 出力先を確認します.
5. `再多重化`を実行します.

処理後, 同じ映像内容の`.mp4`ファイルが作成されます.

---

## 7. OBS側でクロップする場合

VLCで再生時にズームするだけでよい場合は, この設定は不要です.

録画ファイル自体をスクリーン部分だけにしたい場合は, OBS側でクロップします.

### 7.1. Altドラッグによるクロップ

1. `ソース`欄でC922の南京錠をクリックし, ロックを解除します.
2. OBSプレビュー上でC922映像をクリックします.
3. `Alt`キーを押したまま, 赤い枠の辺を内側へドラッグします.
4. 上下左右を調整し, 必要な領域だけ残します.
5. `Alt`キーを離します.
6. C922映像を右クリックします.
7. `変換`を開きます.
8. `画面に合わせる`を選択します.

ショートカットは次のとおりです.

```text
画面に合わせる: Ctrl + F
変換の編集: Ctrl + E
```

### 7.2. クロップ/パッドフィルタを使う方法

数値で正確に設定する場合は, 次の手順を使います.

1. `ソース`欄でC922を選択します.
2. `フィルタ`を押します.
3. `エフェクトフィルタ`欄の`+`を押します.
4. `クロップ/パッド`を追加します.
5. `左`, `上`, `右`, `下`へ削るピクセル数を入力します.
6. フィルタ画面を閉じます.
7. C922を右クリックします.
8. `変換 → 画面に合わせる`を実行します.

クロップは不要部分を削る処理です. 元映像に存在しない細部を復元する機能ではありません.

---

## 8. VLC Media Playerで録画ファイルを開く

1. VLC Media Playerを起動します.
2. `メディア`を開きます.
3. `ファイルを開く`を選択します.
4. OBSで録画したMKVまたはMP4を選択します.

通常再生では, OBSが保存した動画全体が表示されます.

---

## 9. VLCのインタラクティブズームを設定する

### 9.1. インタラクティブズームを有効化する

1. VLCで動画を再生します.
2. `ツール`を開きます.
3. `エフェクトとフィルター`を選択します.
4. `ビデオエフェクト`を開きます.
5. `ジオメトリ`を開きます.
6. `インタラクティブズーム`へチェックを入れます.

有効化すると, 画面左上に次の要素が表示されます.

- 元動画全体を示す小さいナビゲーション画面.
- 現在拡大している範囲を示す選択枠.
- ズーム倍率を調整するコントロール.
- `VLC ZOOM HIDE`という表示.

### 9.2. 拡大する場所を指定する

左上の小さいナビゲーション画面で, 選択枠をドラッグします.

スクリーンがある位置へ選択枠を移動すると, VLCのメイン画面にその部分が拡大表示されます.

ズーム倍率は, 左上のコントロールで調整します.

### 9.3. 左上のナビゲーション画面を消す

調整が終わったら, 左上の小窓付近にある次の表示をクリックします.

```text
VLC ZOOM HIDE
```

これにより, 左上のナビゲーション画面と選択枠が非表示になり, 拡大された映像だけが画面に表示されます.

再び調整したい場合は, 左上に表示される次の項目をクリックします.

```text
VLC ZOOM SHOW
```

### 9.4. インタラクティブズームを無効化する

元のフルフレーム表示へ戻す場合は, 次のチェックを外します.

```text
ツール
→ エフェクトとフィルター
→ ビデオエフェクト
→ ジオメトリ
→ インタラクティブズーム
```

チェックを外すと, Windows標準のメディアプレイヤーで再生した場合と同様に, 元の録画フレーム全体が表示されます.

---

## 10. VLCでフレームがネストして見える場合

VLCのインタラクティブズームを有効にすると, 左上に元動画全体の小窓と選択枠が表示されます.

この状態は, 動画ファイルの中に複数のフレームが録画されているわけではありません. VLCが再生時に表示しているズーム操作用UIです.

次のように見える場合があります.

```text
+-- 元動画全体 ----------------------------+
|  +-- ズーム範囲を示す小窓 ------------+ |
|  |                                      | |
|  +--------------------------------------+ |
+-------------------------------------------+
```

対処方法は次のとおりです.

```text
VLC ZOOM HIDEをクリックする
```

これにより, 外側のナビゲーション表示が消え, ズームされた映像だけが表示されます.

確認方法は次のとおりです.

- Windows標準メディアプレイヤーでは元の録画フレームだけが表示される.
- VLCでインタラクティブズームをOFFにすると, 元の録画フレームだけが表示される.
- VLCでインタラクティブズームをONにし, `VLC ZOOM HIDE`を押すと, 拡大映像だけが表示される.

---

## 11. OBSとVLCのズームの違い

OBS側のクロップと, VLC側のインタラクティブズームは別の機能です.

### OBS側のクロップ

- 録画時に適用されます.
- 保存される動画自体が切り出された状態になります.
- 別のプレイヤーで再生しても, クロップ済み映像になります.

### VLC側のインタラクティブズーム

- 再生時にだけ適用されます.
- 録画ファイル自体は変更されません.
- Windows標準メディアプレイヤーなどでは, 元のフルフレームが表示されます.
- `VLC ZOOM HIDE`でズーム操作用の小窓を隠せます.

用途に応じて次のように使い分けます.

```text
録画ファイル自体をスクリーンだけにしたい
    → OBS側でクロップする

元映像を残し, 再生時だけスクリーンへズームしたい
    → VLCのインタラクティブズームを使う
```

---

## 12. 本番前のテスト

本番前に, 30秒程度のテスト録画を実施してください.

確認項目.

- 1920x1080, 30fpsで録画されている.
- スクリーンの文字にピントが合っている.
- 白いスライドが白飛びしていない.
- スライド切り替え時にフォーカスが動かない.
- 横縞やちらつきがない.
- 音声が必要な場合は, 音声レベルが適切である.
- 保存先に動画ファイルが作成されている.
- VLCでインタラクティブズームが動作する.
- `VLC ZOOM HIDE`で操作用の小窓を消せる.
- Windows標準メディアプレイヤーでは元の録画フレームが表示される.

---

## 13. 推奨設定まとめ

C922で投影スクリーンを録画する場合の推奨値です.

```text
OBS映像キャプチャデバイス
  デバイス: C922 Pro Stream Webcam
  解像度: 1920x1080
  FPS: 30
  映像フォーマット: MJPEGを優先

OBS映像
  基本キャンバス解像度: 1920x1080
  出力解像度: 1920x1080
  FPS: 30

OBS録画
  録画形式: MKV
  録画品質: 高品質, ファイルサイズ中
  エンコーダ: 使用可能なハードウェアH.264エンコーダ
  必要に応じて録画後にMP4へ再多重化

VLC
  ツール
  → エフェクトとフィルター
  → ビデオエフェクト
  → ジオメトリ
  → インタラクティブズーム
  → VLC ZOOM HIDE
```
